## cpp 编写格式（建议）
### 主要结构
分为大块和小块，大块之间双行隔开，小块之间单行隔开即可。以下所述“块”均属于大块。

1. 引用块：`#include` 系列放在文档最前方，尽量把表示数据结构的库（如`<queue>`）单独放在该块的后面，`using`引出的语句放在其最后。
2. 宏常量块：`#define` 系列放在`#include` 系列后方。其中，将科学常数（如`pi222`）和自定义常数（如`TABLE_LENGTH`）分为两个独立小块。
3. 日志块：内容包括`enum Logger`的一个枚举类型、`logger()`日志函数。
4. 设置块：包括可提前修改的常数。有两小块，第一小块是目标位置的`map<int, pair<int, int>>`，如`buckets`,`goals`；第二小块是结构体`struct Config config`，用于存储所有设置信息，包括可修改的和不可修改的设置，且尽量所有在程序中不会发生修改的常量加上`const`。
5. 全局变量块：包括结构体`Point`，所有全局变量（如`hitting_angle`,`ball_position`,`cmd`），机械臂和电机实例声明，和系统块的函数声明（`get_vision`和`get_referee`）。
6. 计算块：包括所有计算的函数或类（如类`LinearPredictor`,`calculate_hitting_angle`）。
7. 主函数块：包括主要控制击球的函数、读取设置文件的函数和主函数。
8. 系统块：`get_vision`, `translate_referee`, `get_referee` 这三个函数属于系统固定函数，按上述顺序放在代码的最后。

### 命名规范
#### 命名格式
所有函数和变量用小写单词与下划线的组合，如`hitting_angle`，`define_speed`。

所有类和结构体用单词组合，每个单词首字母大写，不用下划线连接，如`LinearPredictor`。

所有用`#define`引出的宏常量用大写单词+下划线形式，如`TABLE_WIDTH`。

==类内的变量在一般变量的基础上，末尾加上下划线，如`coming_velocity_`。==结构体内变量、类内函数等命名格式不变。

#### 命名要求
保证能从函数或变量名中能读出函数大概的用途，比如`define_motor_speed`。在此基础上，涉及的名词是公认的，==不要使用别称==，比如击球角度用`hitting_angle`而非`hitting_direction`。

#### 注释
尽量在每个函数前都加上注释，注明本函数的具体用途。

尽量在每个中间变量定义后加上注释。因为中间变量的命名不用严格按照命名格式，所以需要注释与其关联的变量名或注明其用途以增加可读性。

### 特殊要求
1. 涉及地址的，使用绝对路径，且为了跨设备使用，==将绝对路径设置为`config`中已经记录的仓库绝对路径与相对仓库路径的组合==，即`config.repo_path + '\\relative_path'`。
2. 编写代码时，认为一个值可能会随着测试的进行或策略的改变而改变的，一定要将其==写入`config`中==，便于后续的调试与修改。

## 文件命名规范
每个比赛进程设置了文件夹，如`special`表示专项赛，`national`表示国赛。每个文件夹内都存在三个子文件夹`goal`,`dynamic`,`bucket`和一个`config.csv`文件，以及`public`文件夹。这些文件夹表示打门、动态打门、打桶三个赛项。每个文件夹内存储的就是对应赛项使用的所有代码和文件。在不同赛项间有共用文件时，存储在`public`文件夹中，并在需要使用的赛项文件夹中创建快捷方式。

==命名每个`cpp`或`py`等代码文件时==，每个名字由几部分组成，==不同部分之间用下划线隔开==，同一部分之间==用一个小写单词或首字母大写的多个单词组成==（如`jaka`,`GoalAngle`,`goal`,`LowVelocity`）。正常情况下是两部分，表示“调试阶段”“正式比赛阶段”所用的代码。在`special`专项赛期间，用`check`表示“调试所用代码”，用`goal`表示“打门正式比赛代码”。第二部分表示其具体用途，比如调试阶段用于纠正角度的文件用`GoalAngle`。用下划线组合即可。

`csv`文件的命名的格式同上，但是第一部分写为`data`，如`data_GoalAngleCorrection`,`data_trajectory`。

## `logger()`函数使用教程
`logger()`函数可以接受任意多、任意类型的参数。第一个参数是`Logger`类型的，其定义为`enum Logger { Info, Error, Move, Hint, Input }`，里面的值分别代表“信息”，“报错”，“机械臂或电机动作”，“给用户的提示”，“用户输入内容”，作为第一个参数输入。后面可以接受无限多参数，函数会照顺序组成一个字符串并输出。

例如
```cpp
double angle = 10.628;
int n = 2;

logger(Info, "Calculated angle: ", angle, " for ", n, " balls.");
```

输出为
```less
	[Info]  Calculated angle: 10.628 for 2 balls.
```
